Intelbrew

Homebrew bottles for Intel Macs

curl -fsSL https://intelbrew.sh | bash

Paste it into Terminal. It shows every change and asks before making it.

Want a GUI? Get Tankard:

brew install --cask d4rkwyng/tap/tankard
Download

Homebrew no longer builds ready-made packages ("bottles") for Intel Macs, so brew install falls back to compiling from source, which can take a long time. Intelbrew builds them every day on its own Intel macOS builder. Run one command to switch, then use brew as normal.

Is this for me?

  • An Intel Mac (not Apple Silicon).
  • macOS 14 Sonoma or newer (natively, or through OpenCore Legacy Patcher).
  • Not a Core 2 or Penryn CPU. Most Macs from 2010-2011 on work; a few Core i3 models don't.
  • Apple's Command Line Tools. If you don't have them, run xcode-select --install.

The installer checks all of these and stops, without changing anything, if one is missing.

What you'll see

  1. If you already have Homebrew, a choice: press Enter to switch it in place and keep your installed packages.
  2. A list of every change it will make. Type yes and press Enter to go ahead. Anything else stops it with nothing changed.
  3. Possibly your Mac password, if it needs to create folders in /usr/local. Nothing shows on screen while you type it; that's normal.
  4. A one-time download of about 1.3 GB (roughly 5-15 minutes).
  5. A boxed ACTION NEEDED note at the end: quit Terminal and open it again.

To check it worked, in a new Terminal window run brew config | grep GIT_REMOTE. Both lines should mention d4rkwyng. Then use brew install and brew upgrade as usual.

What you get

With an Intelbrew bottle, brew install downloads the finished build and pours it: no compiling. On our builder, hello pours in 3.4 seconds. Without a bottle, the same command compiles from source on your Mac. Build times on our builder (an Intel Sonoma VM):

FormulaWith a bottleBuild from source
llvm 23.1.5pour3 h 16 min
rust 1.100.0pour25 min
node@24 24.22.2pour15.5 min
python@3.14 3.14.9pour4.3 min

Coverage: the top 500 formulae by installs, plus their dependencies, about 880 formulae. Coverage is partial right now while the rebuild backlog fills in.

How it works

Intelbrew publishes intelbrew-core, a fork of homebrew-core with x86_64 Sonoma bottles on its GitHub Releases, rebuilt daily. Homebrew uses it in git mode, set by three lines in your shell profile. Homebrew itself comes from a small fork, d4rkwyng/brew: each upstream release plus one patch for the Intel warning.

Questions

brew install --cask says "No Cask with this name exists"

Casks leave API mode too, so tap them once: brew tap homebrew/cask (about 620 MB). The installer offers this (default No), or pass --casks. Intelbrew does not build or test casks: they are upstream app downloads, each with its own macOS minimum.

Why is a formula building from source?

There's no Intelbrew bottle for it, yet or ever. It may be outside the top set, still in the rebuild backlog, held at its last working version after an Intel build broke, dropped after 8 weeks stuck, or not buildable on our Sonoma builder (for example because it needs a full Xcode). Formulae that depend on an unbuildable one get no bottle either.

How do I go back to upstream Homebrew?

Remove the three export lines from your shell profile, open a new terminal, and run:

git -C "$(brew --repository)" remote set-url origin https://github.com/Homebrew/brew
brew update

Optionally, delete the core clone: brew untap homebrew/core.
